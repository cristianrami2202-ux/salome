# Oso para Salomé 💌🐻

Página interactiva hecha con HTML, CSS y JavaScript (sin dependencias).

## Cómo funciona
1. Empieza con un sobre y corazones flotando.
2. Al tocar el sobre se abre la carta y aparece el oso.
3. El oso escribe mensajes, parpadea, te sigue con la mirada y reacciona si lo tocas.

## Personalizar
Edita el arreglo `MENSAJES` y la constante `NOMBRE` en `script.js`.

## Subir a GitHub y desplegar en Netlify
1. Crea un repositorio nuevo en GitHub y sube estos archivos (`index.html`, `style.css`, `script.js`).
2. En Netlify: **Add new site → Import an existing project → GitHub** y elige el repositorio.
3. Deja el comando de build vacío y la carpeta de publicación en `/` (raíz). Pulsa **Deploy**.

También puedes arrastrar la carpeta completa a https://app.netlify.com/drop
